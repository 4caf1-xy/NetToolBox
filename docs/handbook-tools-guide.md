> 本文件是「七本速查手册 + 子网计算器 + 进制转换 + curl 生成器」的**唯一权威出处**：

### 1.1 数据形态：独立 JSON，与命令库彻底解耦

- 位置：`app/handbook/*.json`，打包时经 `--add-data` 进 exe；
- **不进 `command_lib.db`**：不参与条目计数、不进覆盖度矩阵、不改种子底数（`--validate-seed` 仍为 459 / 26 / 106）；
- 目录解析（与 `seed_dirs` 同口径，`app/handbook.py::handbook_dirs`）：
  1. **程序同目录 `handbook/`** —— 现场整册替换或补一本自定义手册，不必重新打包；
  2. exe 内置 `handbook/` —— 随包发布的七本。
- 同文件名时前者优先；新增自定义手册只要 `doc_id` 不撞车即会自动出现在左侧列表末尾。

### 1.2 JSON 结构（四列固定）

```json
{
  "doc_id": "ports",
  "title": "常用端口",
  "subtitle": "一句话说明",
  "source": "权威来源（写清 IANA / RFC / 官方文档）",
  "updated": "2026-11-02",
  "notes": ["口径与注意事项（逐条显示在「口径说明」里）"],
  "groups": [
    {"name": "分组名", "desc": "分组说明",
     "columns": ["列1", "列2", "列3", "列4"],
     "rows": [["…", "…", "…", "…"]]}
  ]
}
```

- **四列固定**：表格视图、跨册检索、TSV 复制都按 4 列排版；多一列少一列都会被 `--validate-handbook` 拦下；
- 每行 4 个**非空**字符串；单元格允许 `\n` 换行（如 ssh config 片段），表格会按行高自动展开；
- `source` 与 `updated` 必填：离网手册的可信度全靠这两栏，别留空。

### 1.3 分册专属自检（`app/handbook.py`）

| 分册 | 额外校验 |
|---|---|
| `ports` | 端口必须是 1–65535 的整数；传输层只能是 `TCP` / `UDP` / `TCP/UDP`；**同一（端口 + 单协议）不得重复登记**（`TCP/UDP` 行会展开成两条参与查重） |
| `http-status` | 码必须是 3 位数字；**号段必须与分组一致**（5xx 组里放 404 直接报错）；全局唯一 |

## 2. 手册 Tab（速查手册）

- 入口：顶部 Tab「速查手册」（命令库之后）+ 菜单「视图 → 速查手册」（`Ctrl+Shift+H`）；
- 左树两级：**分册 → 分组**（节点带条数，鼠标悬停显示分组说明 / 来源）；右侧表格四列，可整列拖宽；
- **本册搜索**：搜索框只搜当前分册（跨分组），命中行前面多一列「分组」；清空即回到分组视图；
- **跨册搜索**走 `Ctrl+K`（第四库），命中项副标题是「册名 · 分组」，回车直接跳到该行并选中；
- 复制：右键「复制整行 / 复制单元格 / 复制整组（TSV 含表头）」，或直接点「复制整组」；
- 「口径说明 / 来源」按钮展开该册的 `notes` 与来源——现场对数字有疑问时先看这里。

## 4. 子网掩码 / CIDR 计算器

输入：IP（可写 `192.168.1.130/26` 直填，也可 `192.168.1.130 26`）+ 前缀下拉（`/0`–`/32`，下拉项自带掩码提示）；常用前缀按钮 `/8 /16 /24 /28 /30` 一键套用并立即计算。

输出 15 项：IP、前缀、掩码、反掩码、网络地址、广播地址、可用地址范围、可用主机数、地址总数、CIDR、IP/掩码十进制整数、地址分类（A–E 传统分类，仅参考）、地址用途（私有/环回/链路本地/组播/公网/保留）、计数口径。

### 4.1 边界口径（重点）

| 前缀 | 可用主机数 | 网络/广播地址 | 说明 |
|---|---|---|---|
| `/0` | 2³²−2 = 4294967294 | 0.0.0.0 / 255.255.255.255 | 默认路由口径，界面会提示「覆盖过大，确认是否笔误」 |
| `/24` | 254 | 有 | 标准子网 |
| `/30` | 2 | 有 | 点对点互联 |
| `/31` | **2** | **无**（广播列显示 `-`） | RFC 3021 点对点链路，两个地址都可用 |
| `/32` | **1** | **无** | 单主机路由，首末地址相同 |

### 4.2 非法输入一律报错（不静默、不猜测）

| 输入 | 行为 |
|---|---|
| 段数不是 4 / 有非数字段 / 段 >255 | 报错并指出第几段 |
| **前导零**（`192.168.01.1`） | 报错——部分工具按八进制解析，本工具拒绝替你猜 |
| 前缀非 0–32 整数 | 报错并说明允许范围 |
| IP 框带 `/24` 但下拉选 `/16` | 报错「输入冲突」，要求只留一处 |
| 缺前缀 / 空输入 | 报错并给示例 |
| 掩码非连续（`255.0.255.0`） | 报错（掩码转前缀时） |

错误以红字显示在结果区上方，同时**清空结果表**——避免旧结果被误读成新结果。

## 5. 进制转换器

- 源进制：自动识别 / 2 / 8 / 10 / 16；自动档按前缀判定（`0x`→16、`0b`→2、`0o`→8，无前缀按十进制）；
- 输出：二进制（`0b…`）、二进制 4 位分组、八进制（`0o…`）、十进制、十六进制（`0x…`）、有效位数；
- 上限 **64 位**（`2^64−1 = 18446744073709551615`）；输入即时转换，错误即时红字提示。

拒绝的输入：负数（网络场景的地址/掩码/端口都不带符号）、下划线/逗号/空格分隔符、与所选进制不匹配的前缀（如选十进制却输入 `0x1F`）、该进制下非法的数位（二进制里出现 2、十六进制里出现 G）、只有前缀没有数值。

## 6. curl 生成器

### 6.1 表单字段

| 字段 | 说明 / 校验 |
|---|---|
| URL | 必填，必须 `http://` 或 `https://` 开头；含空白或换行直接报错（不做静默编码） |
| 方法 | GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS；HEAD 生成 `--head`；GET 带请求体时显式 `-X GET`（否则 curl 会按 POST 发） |
| 请求头 | 一行一个「名称: 值」；名称只允许 RFC 7230 token 字符；**含回车直接拒绝**（防头注入） |
| 请求体 | 走 `-d`；JSON 但未设 `Content-Type: application/json` 时给告警（不代填） |
| 超时 / 重试 | `--max-time N` / `--retry N`（重试为 0 时不写进命令，避免噪音） |
| `--resolve` | 一行一个 `host:port:ip`，可多行；格式与端口/段范围逐项校验 |
| 开关 | `-k` 跳过证书校验 / `-L` 跟随重定向 / `-sS` 静默但显示错误 |

生成顺序：`curl [-X 方法|--head] [-k] [-L] [-sS] [--max-time] [--retry] [--resolve…] [-H…] [-d 体] URL`（URL 放最后，便于肉眼核对目标）。

### 6.2 三种 shell 的转义规则（跨平台粘贴的核心）

| 目标 | 包裹 | 内层转义 | 备注 |
|---|---|---|---|
| Linux / macOS（bash、zsh） | 单引号 `'…'` | 单引号写成 `'\''` | 可承载换行（多行 JSON 可用） |
| Windows CMD | 双引号 `"…"` | 双引号写成 `\"`（由 curl 自身还原） | 单行；`%` 可能被 cmd 当变量展开，出现时给告警 |
| PowerShell | 单引号 `'…'` | 双引号写成 `\"`，单引号写成 `''` | 单行；绕过 PS 5.1 给原生 exe 传参时的引号吞噬坑 |

只含安全字符（字母数字与 `_@%+=:,./-`）的参数不加引号，保持可读。

### 6.3 明确不做的事

- **不执行**任何命令：只生成文本，复制后由用户自己在终端里跑（与全工具 Copy Only 边界一致）；
- Windows 两种 shell 下**请求体含换行直接报错**：单行命令无法安全承载换行，宁可让用户压成一行或切 Linux 模式，也不偷偷替换换行改变语义；
- 不自动补 `Content-Type`、不自动 URL 编码、不自动剥协议头——全部由用户决定，工具只校验并提示。

## 8. 已知边界（有意为之）

1. **手册是常用集，不是全量**：端口以 IANA 注册表为准但只收常用项；需要完整注册表请查官方 registry（离网现场以产品文档为准）。
2. **端口「未登记」标注不等于不可用**：Redis 6379、MongoDB 27017 等没有 IANA 登记但事实标准如此，本表如实标注，不冒充登记项。
3. **子网计算只做 IPv4**：IPv6 前缀计算（/48 /64 分片规划）未做，需要时另立项。
4. **curl 生成器不覆盖 `--form` 上传、`--cert` 双向认证、`-o` 落盘**：现场需要时按官方文档手工补参数即可，生成结果可直接再接。
5. **Ctrl+K 手册检索按子串匹配**：不做分词与同义词（命令名、端口号、状态码这类精确串命中率已经够高）。
